# 1.1 Change in Tandem

![1.1 Change in Tandem](media/ap-precalc-1-1-change-in-tandem.svg)

## What happens

1. The function machine is a black box carrying the rule $y = f(x) = 4x + 3$: an input $x$ goes in on the left and the output $y$ comes out on the right.
2. Input $x = 0$: the machine computes $4(0) + 3 = 3$, so the output is $y = 3$, a positive value.
3. Input $x = 1$: $4(1) + 3 = 7$. Compared with the previous input, $x$ went up by $1$ and $y$ went up by $4$.
4. Input $x = -2$: $4(-2) + 3 = -5$. Now $x$ went down by $2$ and $y$ went down by $8$.
5. Input $x \to +\infty$: the output $4x + 3 \to +\infty$, so $y$ grows without bound together with $x$.
6. The table of inputs and outputs shows the pattern: every change in $x$ produces a related change in $y$, so the two quantities change in tandem.

## Concept

$$
y = f(x) = 4x + 3, \qquad f(0) = 3, \quad f(1) = 7, \quad f(-2) = -5, \qquad \lim_{x \to +\infty} f(x) = +\infty
$$

A function assigns exactly one output to each input, so once $x$ is chosen, $y$ is determined; the two quantities cannot move independently. For this rule the change in $y$ is always four times the change in $x$: $f(x + \Delta x) - f(x) = 4\,\Delta x$. Because $4 > 0$, $y$ increases whenever $x$ increases and decreases whenever $x$ decreases, and as $x$ grows without bound so does $y$.

## Summary

Two quantities change in tandem when one is a function of the other: choosing the input $x$ fixes the output $y$ , and any change in $x$ produces a related change in $y$ . For $y = 4x + 3$ every change in $x$ produces four times that change in $y$ , so $y$ rises with $x$ and $y \to +\infty$ as $x \to +\infty$ .

### 繁體中文

當一個量是另一個量的函數時，兩個量就會同步變化：選定輸入 $x$ 就決定了輸出 $y$ ，而 $x$ 的任何變化都會引起 $y$ 相應的變化。對 $y = 4x + 3$ 而言， $x$ 的每一個變化都會使 $y$ 產生四倍的變化，因此 $y$ 隨 $x$ 上升，且當 $x \to +\infty$ 時 $y \to +\infty$ 。
