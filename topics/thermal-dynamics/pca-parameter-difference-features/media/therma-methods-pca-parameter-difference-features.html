Step 1: Pixel-Wise Model Fitting

Each lesion pixel's recovery curve is fitted with its own five-parameter double exponential.
Lesion mask L
Every pixel has its own fitted vector $\boldsymbol{\theta}_i$ of five parameters. This differs from how the other features are generated — see the other feature notes.

Step 3: Regional Difference

Absolute difference between the lesion and normal-skin mean parameter vectors.
$$\Delta\boldsymbol{\theta} = \left|\,\textcolor{#dc3545}{\bar{\boldsymbol{\theta}}_L} - \textcolor{#0d6efd}{\bar{\boldsymbol{\theta}}_N}\,\right|$$
↓
$$\Delta\boldsymbol{\theta} = [\Delta\theta_1,\ \Delta\theta_2,\ \Delta\theta_3,\ \Delta\theta_4,\ \Delta\theta_5] \in \mathbb{R}^5$$
One five-value difference vector per case.
